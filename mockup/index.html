Runsheet mockup

The original design for the Fogarty work task manager: five screens. These are static copies, so links between screens work but buttons and checkboxes don't. For the working app built from this design, open the demo app.

Week viewHome screen: the week's tasks and calendar events, with filters and a role switcher.
Create / edit taskTitle, assignee, group, deadline, tags, show number, calendar.
Calendar syncGoogle and Microsoft calendars (managers and admins).
Roles & permissionsWhat each role can do, and the people list (admins).
Shop TV displayView-only screen for the Warehouse and Carpenters.
